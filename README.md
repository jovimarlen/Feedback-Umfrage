# Heimat Distillers – Messe-Umfrage

Kurze Umfrage (5 Fragen) für den Messestand, optimiert für Tablets.

## Online stellen mit GitHub Pages

1. Neues Repository auf GitHub anlegen (z. B. `messe-umfrage`).
2. Auf **Add file → Upload files** klicken und `index.html`, `README.md` und `.nojekyll` hochladen.
3. **Settings → Pages** öffnen, bei *Source* „Deploy from a branch“ wählen, Branch `main` und Ordner `/ (root)`, dann **Save**.
4. Nach ca. 1–2 Minuten ist die Umfrage erreichbar unter
   `https://DEIN-BENUTZERNAME.github.io/messe-umfrage/`

## Bedienung

- **Auswertung öffnen:** 5× schnell auf den Schriftzug oben links tippen.
- **Export:** In der Auswertung „Als CSV exportieren“ (öffnet sich in Excel).
- **Neustart:** Nach der Danke-Seite automatisch, abgebrochene Umfragen nach 90 Sekunden.

## Wichtig

- Die Antworten werden **nur im Browser des jeweiligen Geräts** gespeichert, nicht auf GitHub.
  Jeden Messetag die CSV exportieren.
- Nicht im privaten Modus öffnen, sonst gehen die Antworten beim Schließen verloren.
- Am besten immer dasselbe Gerät und denselben Browser verwenden.
